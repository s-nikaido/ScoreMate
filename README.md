# ScoreMate

紙楽譜を管理するローカル保存版アプリ（買い切り想定・iOS/Android/PC向け）。

## 今回できたこと

- `www/index.html` に、Supabase版から作り直した「ローカル保存（IndexedDB）」版の本体一式が入っています。
- ログイン機能は削除しました（1人の端末内で完結するため不要）。
- データ・写真はすべて端末内のIndexedDBに保存されます。外部サーバーへの通信は一切ありません（Gemini APIキーを設定してAI読み取りを使う場合のみ、その場面だけGoogleと通信します）。
- 機能は元のWeb版とほぼ同じです：曲名・作曲家・パート・演奏会のマスタ管理、傾き・歪み補正（OpenCV.jsによる自動検出＋手動調整）、影のムラ補正、複数画像のPDF化、Gemini APIによるAI読み取り。
- メニューに「書き出し（バックアップ）」「読み込み（復元）」を追加しました。これで1つのファイルにまとめてデータを書き出し、iCloud DriveやGoogle Driveに保存し、別の端末で読み込むことができます。

## 今回、簡略化した部分（要注意）

以前相談した「自動で同期・更新日時を比較して衝突確認」という仕組みは、**今回はまだ実装していません**。今あるのは「ボタンを押して書き出す／読み込む」という手動の方式です。自動同期を作るには、Capacitorでネイティブ化したあとに「Filesystem」プラグインを使って端末のフォルダに直接読み書きする処理を追加する必要があります（下記の次のステップで対応可能です）。

## 動作確認のしかた（今すぐできること）

`www/index.html` をブラウザで直接開くだけで動作します。PC・スマホのブラウザで開いて、一通りの機能を確認してみてください。

## 本物のiOS/Android/PCアプリにする手順（ここからはお使いのPCで）

このサンドボックス環境にはXcode・Android Studioが入っていないため、実際のアプリ化（ビルド）はお使いのPC上で行う必要があります。

1. このフォルダ一式をダウンロードして、ご自分のPCの作業フォルダに置く
2. ターミナルで以下を実行（Node.jsが必要です）
   ```bash
   npm install
   npx cap add ios       # iOSアプリの土台を作成（Macのみ・Xcodeが必要）
   npx cap add android   # Androidアプリの土台を作成（Android Studioが必要）
   npx cap sync
   ```
3. iOS: `npx cap open ios` でXcodeが開くので、実機やシミュレータで動作確認 → App Store Connectで申請
4. Android: `npx cap open android` でAndroid Studioが開くので、実機やエミュレータで動作確認 → Google Playで申請
5. PC版は Electron または Tauri でラップします（次のステップで着手）
